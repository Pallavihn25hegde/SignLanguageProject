# Real-Time ASL Sign Language to Speech Translator

A computer vision and machine learning application that detects American Sign Language (ASL) hand gestures using a webcam and translates them into speech output in real-time.

## Features
- Hand landmark extraction using **MediaPipe Hands**
- Gesture classification using **Scikit-Learn (Random Forest)**
- Text-to-speech feedback via **pyttsx3**
- Real-time video stream processing with **OpenCV**
